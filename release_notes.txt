## 🐦‍⬛ v2.0.0 — Signal-Recorder가 Rookery가 되었습니다

`v1.1.7` 이후 누적된 변경을 한 번에 담은 릴리즈입니다.
**업데이트 전에 아래 「먼저 확인할 것」을 읽어주세요.**

---

## ⚠️ 먼저 확인할 것

### 이름이 바뀌었습니다

`Signal`이 메신저 앱과 겹쳐 검색에서 묻히고, `Recorder`가 기능의 일부만 설명해서
이름을 **Rookery**(떼까마귀의 집단 둥지)로 바꿨습니다. 여러 채널을 한 화면에서
지켜보는 이 프로그램의 구조와 의미가 맞습니다.

GitHub 저장소 주소도 함께 바뀌었습니다. 예전 주소로 들어와도 자동으로 넘어갑니다.

```
https://github.com/eruminyu/Rookery
```

### Discord `!` 명령이 없어졌습니다

`!status`, `!start` 같은 프리픽스 명령을 지우고 **슬래시 커맨드만** 남겼습니다.
`/status`, `/start` 를 사용하세요.

프리픽스 명령 때문에 Discord 개발자 포털에서 **Message Content Intent**를 켜야 했는데,
이제 그럴 필요가 없습니다. 봇 설정이 한 단계 줄었습니다.

### Discord 봇 명령에 권한 검사가 생겼습니다

**이전에는 호출자·채널 검증이 전혀 없었습니다.** 봇을 초대한 서버의 누구나
남의 녹화를 시작하거나 중단할 수 있는 상태였습니다.

이제 설정 → 알림 탭에서 명령을 허용할 사용자 ID와 채널 ID를 지정할 수 있습니다.
아무것도 지정하지 않으면 **알림 채널에서만** 명령이 동작하고, 알림 채널조차
설정되어 있지 않으면 모든 명령이 거부됩니다.

> 지금까지 알림 채널이 아닌 곳에서 명령을 쓰셨다면 거부됩니다. 설정에서 채널을 지정해 주세요.

### 설치·업데이트 명령이 바뀌었습니다

흩어져 있던 스크립트 8개를 하나로 합쳤습니다.

```bash
curl -fsSL https://raw.githubusercontent.com/eruminyu/Rookery/main/scripts/manage.sh | bash
```

이 한 줄이 **설치와 업데이트를 겸합니다.** 설치되어 있지 않으면 설치하고,
이미 있으면 최신 버전으로 갱신한 뒤 재시작합니다.

설치 후에는 어디서나 한 단어로 관리합니다.

```
rookery status | update | start | stop | logs | --help
```

Windows는 `scripts\manage.bat` 을 쓰세요. Docker로 띄우는 경우에는 이 스크립트를
쓰지 않고 `docker compose up --build -d` 를 그대로 사용하시면 됩니다.

## ✅ 자동으로 처리되는 것 — 따로 하실 일 없습니다

- **DB 파일** `signal_recorder.db` → `rookery.db` 로 첫 실행 때 자동 이관됩니다.
  채널 목록, 녹화·VOD 이력, 태그가 그대로 유지됩니다.
- **systemd 서비스** 이름이 `rookery` 로 바뀝니다. 구버전 서비스는 자동으로 제거됩니다.
- **설치 경로** 가 `~/rookery` 로 바뀌지만, 기존 `~/signal-recorder` 설치가 있으면
  그대로 이어서 사용합니다.
- **페이지 제목** 을 직접 바꾸지 않으셨다면 새 이름으로 갱신됩니다.
  직접 지정하신 제목은 그대로 유지됩니다.

## 🎁 새로운 기능

### 알림이 더 쉬워졌습니다

설정 → 알림 화면을 **Webhook 우선**으로 바꿨습니다. Discord 채널 설정에서 URL 하나만
복사하면 끝이고, 봇을 만들지 않아도 모든 알림이 정상 동작합니다.
봇은 "원격 제어까지 하고 싶을 때" 펼치는 선택 항목으로 내렸습니다.

알림 파이프라인 자체도 새로 만들었습니다.

- 큐 기반이라 연결이 끊겨도 알림을 잃지 않고, 복구되면 밀린 알림을 보냅니다
- 봇이 죽어 있으면 Webhook으로 자동 전환됩니다
- 알림 종류별 on/off, 멘션 대상, 유효 시간(TTL)을 화면에서 설정합니다
- 대기·전송·폐기·만료 건수를 실시간으로 확인할 수 있습니다

### 저장소를 SQLite로 통합

채널 목록·녹화 이력·VOD 이력·태그·대기 알림이 각각 별도 JSON 파일에 흩어져 있던 것을
`data/rookery.db` 하나로 합쳤습니다. 기존 JSON은 첫 실행 때 자동 이관되며,
원본은 지우지 않고 `.migrated` 를 붙여 보관합니다.

- **녹화 종료가 빨라졌습니다.** 이전에는 이력을 저장할 때마다 파일 전체를 다시 썼습니다
- **WAL 모드**로 동작해 녹화 중 전원이 꺼져도 데이터가 깨지지 않습니다
- 라이브 감지 통계가 재시작 후에도 유지됩니다

### 화면 개편

- 대시보드 카드/리스트 보기 전환, 상태·태그 필터, 전체 즉시 스캔
- 채널 카드를 드래그하거나 방향키로 순서 변경
- `Ctrl + K` 명령 팔레트, 알림 센터
- 설정을 7개 탭으로 분리
- 페이지 제목, 파비콘, 포인트 컬러를 브라우저별로 지정

### X Spaces

- 감지한 master URL을 텍스트 파일로 백업해 녹화가 실패해도 수동 다운로드가 가능합니다
- 채널 등록 없이 Space URL만으로 바로 다운로드할 수 있습니다

## 🔧 고친 것

- **X Spaces가 끝났는데 계속 라이브로 표시되던 문제** — 종료된 Space가 타임라인에
  남아 있어 계속 감지되던 것이 원인이었습니다. `.part` 파일이 남는 문제도 함께 해결됐습니다
- **다음 Space의 master URL이 캡처되지 않던 문제**
- **자동 녹화 토글이 간헐적으로 반영되지 않던 문제**
- **실행 위치에 따라 VOD 이력과 태그가 다른 파일에 저장되던 문제**
- 태그가 추가한 순서대로 표시되지 않던 문제

## 📌 참고

- 이 프로그램은 **개인 소장 용도**로 제작되었습니다. 각 플랫폼의 약관과 저작권법을
  확인하고 준수해 주세요.

- 문제가 생기면 `rookery status --full` 로 상태를 점검할 수 있습니다.
